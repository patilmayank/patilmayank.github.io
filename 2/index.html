1.1 Convolutions from Scratch

A convolution is the operation of applying a filter to an image by placing the filter on top of each pixel and computing a dot product, then taking the mean to determine the new value of the pixel. It is calculated by taking the cross-correlation, except the filter is flipped across both the x and y axis before it is applied. Here is my implementation With four loops and two loops. The comparison with scipy.signal.convolve2d is that the library function is much faster than the four loop implementation. My four loop implementation is very slow and takes lots of computations, but the two-loop version is slightly faster. scipy.signal.convolve2d likely has many optimizations such as better batching and caching that speeds up the runtime compared the manual loops. For boundaries, my implementation pads the original input with 0s, and then applies the convolution. On the other hand, scipy.signal.convolve2d has different boundary options, and can do fill with a default value such as 0 which I implemented in my function. It can also handle wrapping and symmetrical boundaries for different effects, such as not creating edges at the boundary of the image.

      def convolve_four_loops(im1, im2):
          im2 = im2[::-1,::-1]
          filter_x_radius = im2.shape[0] // 2
          filter_y_radius = im2.shape[1] // 2
          kernel_area = im2.shape[0] * im2.shape[1]
          res = np.zeros(im1.shape)
          for src_i in range(im1.shape[0]):
              for src_j in range(im1.shape[1]):
                  for dx in range(-filter_x_radius, filter_x_radius + 1):
                      for dy in range(-filter_y_radius, filter_y_radius + 1):
                          x = src_i + dx
                          y = src_j + dy
                          if 0 <= x < im1.shape[0] and 0 <= y < im1.shape[1]:
                              res[src_i][src_j] += im2[dx+filter_x_radius][dy+filter_y_radius] * im1[x][y]
          return res / kernel_area

      def convolve_two_loops(im1, im2):
          im2 = im2[::-1,::-1]
          filter_x_radius = im2.shape[0] // 2
          filter_y_radius = im2.shape[1] // 2
          padded = np.pad(im1, (filter_x_radius*2, filter_y_radius*2))
          res = np.zeros(im1.shape)
          for src_i in range(im1.shape[0]):
              for src_j in range(im1.shape[1]):
                  im1_chunk = padded[src_i:src_i+2*filter_x_radius+1, src_j:src_j+2*filter_y_radius+1]
                  res[src_i][src_j] = np.mean(im2*im1_chunk)
          return res

1.3 Derivative of Gaussian (DoG) Filter

I used a 9x9 gaussian kernel and convolved it with the cameraman to make a smoothed image. I then applied the same dx and dy filters to get the partial derivatives and then took the magnitude and binarized the output. The resulting edges were more defined and there was much less noise at the same threshold of 0.23 than the gradient magnitude binarization applied to the original image.

Convolve the gaussian with D_x and D_y and display the resulting DoG filters as images. Applying one filter to the image however, is faster computationally than performing 2 sequential convolutions.

Part 2: Fun with Frequencies

2.1 Image Sharpening (Unsharp Mask)

I implemented the unsharp mask filter by combining the gaussian filter with a unit impulse in a linear combination. We can get the high frequency image by subtracting the smoothed image from the original, which basically highlights the edges. In order to sharpen the image, we need to do something that will in effect do the opposite of the smoothing that gaussian does, and for that we negate the gaussian and apply it as a filter. However, this is not complete because we need some way to highilght the bright pixel values, ie edges. To do this I used an all 0s filter with the center very bright so the individual pixel is preserved with higher intensity. The negated gaussian has the inverse effect by removing any smoothing and ends up emphasizing the edges throughout the image. Varying the sharpening amount as I did with alpha = 5 and alpha = 10 causes different levels of intensity on the edges in relation to the rest of the image. For the image of Soham, the COSTCO logo in the background becomes sharper and easier to read as alpha increases, because the smoothing with the surroundings is reduced and the edges are highlighted more strongly.

Blurring an image and then sharpening the blurred image: The sharpened blur is closer to the original image in terms of the intensity of its edges compared to the blur. The cancelling out of the blur is not exactly an inverse, but it does fairly well to get close to the original image in terms of the sharpness.

2.2 Hybrid Images

When viewed up close, the fine details of an image (high frequencies) stand out, while from farther away, the broader structures (low frequencies) become more prominent. By blending the low-frequency content of one image with the high-frequency content of another, we can create a hybrid image that changes appearance depending on the viewing distance.
